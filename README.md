# MiaoWaa / Loon

**个人自用的 Loon 插件及脚本备份仓库，仅用于个人使用、学习、研究与备份，不用于任何商业用途。**

本仓库主要用于整理、备份及维护个人日常使用的 Loon 插件与相关脚本，方便设备配置恢复和日常更新。

部分功能参考公开项目，并根据个人使用需求进行适配与调整。

## 📦 插件列表

### 1. Emby 线路切换

支持手动切换与定时自动切换 Emby 播放线路，适用于普通线路与专线分时使用的场景。

**主要功能**

- 手动执行脚本，切换普通线路或专线。
- 每天北京时间 19:00 自动切换至专线。
- 每天北京时间 02:00 自动恢复普通线路。
- 支持自定义主策略组、普通线路及专线策略组名称。

**默认配置**

| 设置 | 默认值 |
|---|---|
| 主策略组 | `Emby` |
| 普通线路策略组 | `EM-D` |
| 专线策略组 | `EM-P` |

**插件地址**

https://raw.githubusercontent.com/MiaoWaa/loon/main/plugins/emby-auto-switch.plugin

### 2. AI 解锁筛选

整合 ChatGPT 与 Gemini 节点可用性检测功能，通过手动执行脚本，筛选并选中对应策略组中的可用节点。

**主要功能**

- ChatGPT 节点可用性检测与筛选。
- Gemini 节点可用性检测与筛选。
- 两项检测脚本独立执行，互不影响。
- 自动选中检测通过的节点。
- 支持自定义 ChatGPT 和 Gemini 策略组名称。

**默认配置**

| 设置 | 默认值 |
|---|---|
| ChatGPT 策略组 | `ChatGPT` |
| Gemini 策略组 | `Gemini` |

**插件地址**

https://raw.githubusercontent.com/MiaoWaa/loon/main/plugins/ai/ai-unlock-filter.plugin

### 3. YouTube 反向筛选

通过检测节点的 YouTube Premium 地区支持情况，反向筛选不支持 Premium 的节点，尝试达到减少广告的效果。

**主要功能**

- 检测节点的 YouTube Premium 地区支持情况。
- 反向筛选明确不支持 Premium 的节点。
- 自动选中符合条件的节点。
- 支持自定义 YouTube 策略组名称。
- 手动执行筛选，不会定时自动运行。

**默认配置**

| 设置 | 默认值 |
|---|---|
| YouTube 策略组 | `YouTube` |

**插件地址**

https://raw.githubusercontent.com/MiaoWaa/loon/main/plugins/youtube/youtube-premium-reverse.plugin

## ⚙️ 使用说明

1. 在 Loon 中通过对应插件地址安装插件。
2. 进入插件设置，确认策略组名称与当前 Loon 配置一致。
3. 根据需要手动执行筛选或线路切换脚本。
4. Emby 定时任务随插件启用自动运行，AI 和 YouTube 筛选脚本需手动执行。
5. 插件更新后，建议检查参数配置及脚本执行结果。

## 📌 注意事项

- 本仓库插件依赖 Loon 的策略组及脚本功能。
- AI 检测结果仅代表检测时的可用状态，不保证所有服务功能均可正常使用。
- YouTube 反向筛选不保证完全去除广告，实际效果取决于节点地区及 YouTube 的广告策略。
- Emby 插件仅负责策略组线路切换，不提供节点测速、服务器状态检测或自动故障转移。
- 使用前请确保对应策略组已正确配置。
- 本仓库内容根据个人需求维护，不保证兼容所有配置或使用环境。
